# Notes UI5 — B4 mobile navigation preview

**Base:** Notes a419c7e8392b6fabddd57eb0115dab9d1bacd35f. Factory baseline 3481a8190a5db5965bb22f84832094268d05be98, Master v27 / Golden Index v28.
**Status:** code present behind independent compile-time visual flag default OFF, physical QA pending.

## What changes with UI5 nav preview
- For widths under 900dp: five bottom destinations Home, Notes, Tasks, Diary, Spaces, with full EN/IT/ES/FR/DE/PT labels and selected icons.
- AppBar adds explicit Search icon. Its callback goes to the **existing section 5** NotesScreen(searchMode: true). Quick Switcher (Ctrl+K), Ctrl+Shift+F, deep links, reminder/Shared Spaces actions and state still use canonical section indices.
- When Search section 5 is active, the five-tab bar highlights Notes (index 1), never invalid index 5. Returning to Notes sets canonical section 1 via _selectSection and leaves query handoff to existing screen logic.
- >=900dp uses **unchanged** six-destination NavigationRail, including Search. In regular mobile builds the original six bottom destinations remain.
- Pure navigation model and tests cover 5 indices, Search fallback and six localizations. No second Navigator, storage, schema, account/session or signing changes.

## QA / release gate
To preview UI5 nav in a local QA build, pass --dart-define=NOTES_UI5_NAV_PREVIEW=true. This does NOT turn on the separate Home UI5 preview or Smart Inbox Project Link QA. Default builds remain unchanged.
- Verify 320/360/393dp, portrait/landscape, textScaler 2.0, keyboard, TalkBack, long localized names.
- Deep link to Diary/Tasks/Shared item and Search, account switch, pending query and backstack, quick switcher and Ctrl+Shift+F.
- Test narrow and wide transitions while Search (section 5) is active; no selectedIndex out of bounds.
- Review exact-head Flutter CI, Web and device screenshots before default-on promotion.
- Changes are UI only; issue #71 production signer and #46 cross-store source ACL remain independent.
