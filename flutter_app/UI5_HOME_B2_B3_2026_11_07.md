# Notes UI5 — B2/B3: Home progressive disclosure, first runnable slice

**Branch base:** Notes a419c7e8392b6fabddd57eb0115dab9d1bacd35f. **Factory baseline:** 3481a8190a5db5965bb22f84832094268d05be98 (Master v27 / Index v28).
**Status:** implemented behind visual preview flag, not default-on release. **No device screenshot or physical certification.**

## Shipped
- HomeUi5Projection derives page count, pending tasks, and **at most three recent authorized pages** from the caller's already-scoped personal-note list. O(N * 3), immutable output, deterministic sorting on updatedAt/ID, no new database/telemetry/storage. 5,000-note test.
- UI5 entry-point text in EN/IT/ES/FR/DE/PT with parity test; date via MaterialLocalizations.
- New UI5 Home sections: localized hero, bounded today briefing, two quick actions, **Continue** (3 recent), **To review** (2 of max 3, expand on demand), and collapsed **Tools** for all existing Study/Projects/Graph/Automation/Sketch/Focus, Document Delta, Privacy Shield and collections.
- Every action goes through existing screen callbacks and canonical routes; existing Smart Inbox preview, source revision checks, dismissal, snooze, mute, task writer and guarded project QA callback are unchanged.
- HomeScreen.ui5Preview defaults to const bool.fromEnvironment('NOTES_UI5_HOME_PREVIEW', defaultValue: false). Ordinary builds use existing Home; test/QA can enable with --dart-define=NOTES_UI5_HOME_PREVIEW=true. A distinct UI5 preview flag is **not** the Smart Inbox project-link debug flag.
- Old Home's Compare/Privacy button actions refactored into the same shared methods used by new Home; no duplicate writer.
- Screen widget tests cover preview rendering, quick actions, recent note callback and expanded advanced tools.
